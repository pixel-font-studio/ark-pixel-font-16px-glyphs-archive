# 方舟像素字体 - 16px 废弃字形归档

本仓库用于归档 [「方舟像素字体」](https://github.com/TakWolf/ark-pixel-font) 中已废弃的 16px 字形相关素材。

仓库包含字形图片素材与字体度量配置文件，不包含字体构建程序。

原仓库的 [2026.09.01](https://github.com/TakWolf/ark-pixel-font/releases/tag/2026.09.01) 版本是最后一个包含 16px 字体的可用构建，本仓库中的素材与该版本保持一致。如需构建字体，请使用该版本提供的构建程序。

## 为什么废弃 16px 字体？

16px 字体实际上只包含少量汉字。从泛中日韩字符集的角度来看，它从未达到实用标准，也没有类似 [「缝合像素字体」](https://github.com/TakWolf/fusion-pixel-font) 的过渡方案。

社区已有 [Unifont](https://unifoundry.com/unifont/index.html) 这一成熟方案。尽管 Unifont 是 16px 宋体，与「方舟像素字体」的风格不同，但它拥有更完整的字符覆盖，能够满足实际使用需求。

「方舟像素字体」16px 版本的泛拉丁字符与符号区相对完善，私用区中的「游戏控制器」符号也可正常使用。然而，拉丁字母的设计尚未达到我们的预期，目前也没有找到合适的改进方向。

## 未来会重启吗？

目前尚未确定。现阶段我们会优先完成 10px 和 12px 字体的开发，之后再看看情况。也许在这期间社区中会做点什么出来。
